- Durata della modalità «Tempo reale» impostabile accanto al pulsante «Tempo reale» (da 15 minuti a 8 ore, 1 ora predefinita)

- Webhook: aggiornamento immediato a ogni push (URL mostrato per ogni plugin)
- Modalità «Tempo reale»: verifica ogni 10 secondi per 1 ora

- Aggiornamento automatico a ogni nuovo commit (opzione «Auto» per plugin, verifica ogni 5 minuti)

- Prima versione: elenco dei plugin seguiti (repository, branch, token cifrato), aggiornamento dal branch, verifica dei nuovi commit
- Repository Gogs, Gitea e GitHub
- Funzione di aggiornamento del plugin eseguita dopo la copia dei file
