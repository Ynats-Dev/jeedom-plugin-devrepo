# DevRepo — plugin Jeedom

Met à jour des plugins Jeedom en développement depuis une branche de leur dépôt (Gogs, Gitea ou GitHub), sans git sur la box.

Documentation : [docs/fr_FR/index.md](docs/fr_FR/index.md)

## Installation (développement)

Copier le dossier dans `/var/www/html/plugins/devrepo` sur la box Jeedom (le nom du dossier doit être l'id du plugin), puis activer le plugin depuis la gestion des plugins. DevRepo peut ensuite se mettre à jour lui-même.
